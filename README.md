# 项目架构学习助手

面向零基础学习者的 Agent Skill，帮助你理解一个项目的架构、实现方法和设计取舍，并规划如何从零制作简化版。

## 能做什么

- 从具体使用场景出发，解释项目解决的问题、输入和输出。
- 用模块分工和一条真实执行链路讲清项目如何工作。
- 解释必要术语、关键代码以及项目与第三方依赖各自承担的工作。
- 根据源码与文档提供依据，区分已确认事实、文档描述和推测。
- 给出必要前置知识、分阶段制作路线、可检查的产物和验收方法。

## 文件结构

```text
project-architecture-tutor/
├── SKILL.md               # 完整指令
└── agents/
    └── openai.yaml        # 界面名称、简介和默认提示词
```

## 使用方法

在支持 Agent Skills 的工具中加载 `project-architecture-tutor` 文件夹，然后提供项目仓库链接、本地源码路径，或 README、目录和关键代码等材料。

示例提示词：

```text
请使用 $project-architecture-tutor 分析这个项目：[项目链接或本地路径]。
把我当作零基础学习者，先说明它解决什么问题，
再用一条真实功能链路讲清架构和实现，解释必要术语，
区分已确认事实与推测，最后给出分阶段制作简化版的路线和验收标准。
```

也可以直接将 [SKILL.md](project-architecture-tutor/SKILL.md) 的正文作为提示词使用。

默认交付分析与学习指导；需要实际编写或修改代码时，请在请求中说明。只有说明文档、无法查看源码时，分析会明确其证据范围。
